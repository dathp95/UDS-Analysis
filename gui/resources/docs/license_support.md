# License Support Guide

## 1. Free Trial

The application shows a Free Trial plan with the first 2 months free. This is UI information only in the current screen.

## 2. Select License Duration

Choose a license duration from the Duration list. The displayed price is a demo UI value and does not update the real license system.

## 3. Payment

Scan the payment QR code in the License & Support panel to complete payment with the administrator.

## 4. Copy Device ID

Use Copy ID to copy the displayed Device ID. The current value is a placeholder while the activation workflow is being prepared.

## 5. Send Device ID To Administrator

After payment, send the Device ID to the administrator so they can prepare the activation key when backend activation is available.

## 6. Receive Activation Key

The administrator will provide an activation key through the agreed support channel.

## 7. Paste Activation Key

Paste the activation key into the Activation Key field. This field is ready for long keys.

## 8. Activate

The Activate button is present for the prepared workflow. It does not perform real activation in this UI-only version.

## 9. License Renewal

When a license is close to expiration, choose a new duration, complete payment, and contact the administrator for renewal support.
